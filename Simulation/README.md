# Simulations of B1 electronics

## Common requirements
The simulation takes place in LTSpice.

For addtional components we need the symbols and libraries from ltwiki.org. 

Use `wget -np -r -m -k https://www.ltwiki.org/files/LTspiceIV/` to mirror.
Then
1. Add lib/sym to symbols path in LTSpice
  -> %DOWNLOADPATH%\www.ltwiki.org\files\LTspiceIV\lib\sym\Dig_Add\74HC
2. Add lib/sub to libraries path
